# 아티팩트 링크를 로컬 원본과 잇기

`claude.ai/artifact/…` 주소는 Claude Code 세션에서 열리지 않습니다. 웹으로 가져오면 로그인 화면만 오고, Claude Docs 읽기 도구는 접근을 거절합니다(2026년 11월 21일에 확인). 링크는 「이런 아티팩트가 있다」는 단서로 쓰고, 내용은 로컬 HTML에서 읽습니다.

짝 표의 상태 칸에는 `짝`, `짝 없음`, `여럿`(제목이 같은 HTML이 둘 이상), `쓰지 않음`(이스타가 쓰지 않는다고 답함), `링크 없음`(로컬 HTML만 있음) 가운데 하나를 적습니다.

## 순서

1. 스크립트가 PR 본문, 노션 원고, 보고에서 링크와 링크 글을 뽑아 `sources.scan.json`의 `artifactPairs`에 넣습니다.
2. 스크립트가 링크 글과 로컬 HTML의 `<title>`을 공백과 문장 부호를 빼고 견줘, 같으면 `짝`으로 적습니다.
3. `짝 없음`인 링크는 사람이 하듯 한 번 더 찾습니다.
   - 지시문 파일(`agent-*-brief.md`)에 적힌 파일 경로와 제목
   - 링크가 적힌 문서를 고친 날과 가까운 날짜의 HTML
   - 링크 글의 낱말이 본문 첫 제목에 있는 HTML
4. 그래도 없으면 이스타에게 부탁합니다. 아티팩트 화면의 내려받기로 HTML을 받아 작업 폴더의 `inbox/`에 넣어 달라고 하고, 쓰지 않을 아티팩트면 「쓰지 않음」이라고 답해 달라고 합니다.
5. `inbox/`에 파일이 들어오면 `--root`로 더해 다시 훑습니다.
6. 로컬에는 있는데 링크가 없는 HTML도 자료입니다. 목록에 두고 「링크 없음」이라고 적습니다.

## 하지 않는 일

- 링크 글로 내용을 짐작해 적지 않습니다.
- 아티팩트를 만든 대화를 찾아 읽지 않습니다. 정본 11장이 대화 내용을 글에 넣지 못하게 합니다.
- 아티팩트의 설명을 사실로 믿고 적지 않습니다. 사실인지는 fact-check-post가 공식 문서로 확인합니다(정본 7.4).

제목이 다른로컬 HTML을 짝 후보로 받은 경우 `--artifact-candidate "{아티팩트URL}={HTML절대경로}"`를 더합니다. 자료 목록에 「짝 후보: 경로 (이스타 확인)」로만 적고 자동 짝은 만들지 않습니다. 확정은 이스타가 합니다.
