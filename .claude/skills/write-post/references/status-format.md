# 진행 상태 형식

```markdown
# 글 작업 상태: example-work

- 주제: 긴 목록 가상화
- 글: (개요 확정 뒤 적음)
- 고친 날: YYYY-MM-DD

| 순서 | 단계 | 맡은 에이전트 | 결과 파일 | 상태 | 검사 | 메모 |
|---|---|---|---|---|---|---|
| 1 | 자료 모으기 | code (Opus) | sources.md | 하는 중 | | |

## 이스타에게 물은 것과 답

- YYYY-MM-DD 자료 확인: answers/sources-answer-1.txt

## 아직 있는 〔이스타 확인〕 표시

| 글 | 줄 | 내용 |
|---|---|---|
```

상태는 `아직`, `하는 중`, `기다림`, `끝남`, `막힘` 가운데 하나입니다. `막힘`인 단계가 있으면 뒤 단계로 넘어가지 않습니다. 검사하지 않은 결과는 `끝남`으로 적지 않습니다. 작업을 이어 갈 때 결과 파일을 다시 검사합니다.
