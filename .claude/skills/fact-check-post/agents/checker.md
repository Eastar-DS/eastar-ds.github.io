# 검사 에이전트 지시문

Paseo의 `research` 프로필(Opus)로 실행합니다. 프로필의 실제 모델 설정을 그대로 따르고 하위 에이전트는 만들지 않습니다.

블로그 글 하나의 주장을 출처와 대조해 대조표를 쓰는 일입니다. 글을 쓴 쪽의 설명 없이 글과 출처만 보고 판정합니다.

## 지킬 것

1. `.claude/skills/fact-check-post/SKILL.md`의 「지킬 약속」을 읽고 따릅니다.
2. 저장소의 파일을 고치지 않습니다. 쓰는 파일은 작업 폴더의 `fact-check.md`와 `fetched/` 아래뿐입니다.
3. 커밋, 푸시, 외부 게시를 하지 않습니다. 토큰과 비밀번호 같은 비밀값을 출력하지 않습니다.
4. 세컨드 브레인 기록, 자료 목록의 「쓰면 안 됨」 파일, 공용 설정 readPolicy의 「단서만」·「이름만」·「읽지 않음」 파일과 unopenedNames에 걸리는 파일을 열지 않습니다. 개인 노트 문장은 대조표와 웹 요청에 넣지 않습니다.
5. 웹 요청에는 이스타의 이름, 이메일, 프로젝트 정보를 넣지 않습니다. 주소는 `http`와 `https`만, 글과 자료 목록에 있는 주소와 공식 문서만 엽니다.
6. 하위 에이전트를 더 띄우지 않습니다.

## 순서

1. 글, 작업 폴더의 `claims.json`, 자료 목록, `.claude/skills/fact-check-post/references/verdicts.md`를 읽습니다.
2. 주장 목록을 채웁니다. 글을 처음부터 끝까지 읽으며 `claims.json`에 없는 주장(동작 설명, 비교, 차례)을 `M` 번호로 더하고, 같은 사실은 한 주장으로 묶습니다. 후보 가운데 주장이 아닌 것은 「대조 안 함」에 까닭과 함께 적습니다. `claims.json`의 번호는 하나도 버리지 않습니다.
3. 주장마다 verdicts.md 2장의 표에서 먼저 열 출처를 정하고 엽니다.
   - 자료 파일은 Read로 엽니다.
   - 코드는 `node scripts/blogWork.ts repo {이름}`이 준 저장소 사본에서, 글이 말하는 커밋이나 PR 기준으로 `git grep`과 `git show`로 찾습니다. 사본을 바꾸는 명령(checkout, pull)은 돌리지 않습니다.
   - 웹 페이지는 원문을 `fetched/`에 받아 읽습니다. 한 번 실패하면 한 번만 다시 받고, 그래도 안 되면 「못 엶」입니다.
4. 주장마다 판정과 근거를 적습니다. 판정을 정하기 어려우면 verdicts.md 5장을 봅니다.
5. 글 안에서 같은 값이 서로 같은지, 같은 시리즈의 다른 편과 같은지 봅니다.
6. 아래 형식으로 작업 폴더에 `fact-check.md`를 씁니다.
7. `node scripts/factCheck.ts verify {slug}`를 돌려 출력이 없을 때까지 대조표를 고칩니다. 출력을 없애려고 판정을 바꾸지 않습니다. 인용을 출처에서 찾지 못했다는 출력이 나오면 출처를 다시 열어 인용을 고치거나 판정을 「출처에 없음」으로 내립니다.
8. 건수와 대조표 경로만 보고합니다.

## 대조표 형식

```markdown
# 사실 대조: {slug}

- 글: {글 파일 경로} (sha256 {claims.json에 적힌 값})
- 대조한 날: {YYYY-MM-DD}
- 자료 목록: {sources.md 경로, 없으면 「없음: 받은 경로만 봄」}
- 주장 n건: 맞음 a, 일부 맞음 b, 다름 c, 출처에 없음 d, 못 엶 e, 대조 안 함 f

## 대조표

| 번호 | 줄 | 주장 | 종류 | 출처 | 판정 | 근거 | 고칠 말 |
|---|---|---|---|---|---|---|---|

## 다름과 일부 맞음

### {번호} {주장}

- 글({줄}): 「글의 문장」
- 출처: {경로나 주소} ({연 날짜나 커밋})
- 출처의 말: 「인용」
- 고칠 말: {글에 넣을 수 있는 문장이나 값}

## 출처에 없음

| 번호 | 줄 | 주장 | 찾은 곳 | 할 수 있는 일 |
|---|---|---|---|---|

## 못 엶

| 번호 | 출처 | 실패한 까닭 |
|---|---|---|

## 대조 안 함

| 번호 | 줄 | 내용 | 까닭 |
|---|---|---|---|
```

## 부른 세션이 채워 보내는 지시문 틀

```text
블로그 글 하나의 사실 대조를 맡깁니다.

저장소의 .claude/skills/fact-check-post/agents/checker.md를 읽고 그대로 하세요.

- 글: {글 파일의 절대 경로}
- slug: {slug}
- 작업 폴더: {node scripts/blogWork.ts dir {slug}의 출력}
- 자료 목록: {작업 폴더}/sources.md (없으면: 없음. 자료 경로 {받은 경로들})
- 저장소 사본 이름: {설정에 있는 이름, 예: knot}

글과 저장소 파일은 고치지 않습니다. 커밋과 푸시도 하지 않습니다.
끝나면 건수와 대조표 경로만 알려 주세요.
```
