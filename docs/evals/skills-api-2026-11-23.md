### 사실 대조 실행 방식과 verify·status

같은 Claude 독립 세션에서 검사자 역할까지 수행했다. 현재 스킬에는 MCP가 없고 글을 쓰지 않은 세션이 직접 대조하는 경로가 있다. 새 에이전트를 만들지 않고 주장 추출·출처 열기·대조표·verify·status까지 평가할 수 있어 이 방식을 골랐다. 다른 모델의 독립 검사 효과와 검사자 지시문만 만드는 단계는 측정하지 않았다.

| fact-number-with | 통과 | 최신(2026-11-23): 다름 1, 일부 맞음 14, 출처에 없음 0, 못 엶 0 |

## 도구와 검증

- `scripts/skillApiEval.mjs`: 키 전용 환경, 인증 확인, 사본, 도구 제한, 지출 예약·정산, 재시작 시 중복 방지
- `scripts/gradeSkillApiGather.mjs`: 기존 검사기와 생성물·도구 기록의 정량 검사
- `scripts/summarizeSkillApiEval.mjs`: 원본 자료나 실제 자료 경로를 옮기지 않는 공유용 요약
- skill-creator의 run_eval.py는 첫 호출 직후 종료해 최종 비용을 놓치므로, 같은 Skill·Read 판정을 쓰되 result까지 받는 실행기로 바꿈

실행 예:

```sh
pnpm install --frozen-lockfile
node scripts/skillApiEval.mjs triggers "$EVAL_DIR"
node scripts/skillApiEval.mjs run "$EVAL_DIR" "$EVAL_DIR/manifest.json"
node scripts/summarizeSkillApiEval.mjs "$EVAL_DIR" summary.json
```

EVAL_DIR는 저장소 밖 폴더다. 비교 manifest와 평가용 설정도 그 안에 둔다. 비교 manifest는 id, category, cwd(평가 copies 아래), prompt, budget, maxTurns, env.BLOG_WORK_CONFIG를 받는다. 없음 조건에는 disabledSkill을 적어 init 목록을 확인한다. prepareCopy를 호출한 뒤 기존 재료 생성기로 사본을 만들고 대상 스킬 폴더만 뺀다. 중단된 실행은 로그를 정산한 뒤 잠금을 해제해야 한다. API 키를 셸 명령에 넣지 않는다.

검증: API 실행기의 인증·예산 테스트 4개 포함 전체 테스트 497개, pnpm check, pnpm build, pnpm post:evals 13개 검사 통과. 빌드가 다시 만든 글꼴 파일은 이번 평가와 무관해 원래 상태로 돌렸다.

## 남은 예산으로 할 일

1. 수정한 description의 독립 질문과 인접 음성 질문을 먼저 평가한다. 현재 건당 약 $0.10이므로 10~20건에 약 $1~2를 예상할 수 있다.
